Tecnologías

Lenguajes, frameworks y plataformas utilizadas

  • HTML

    • HTML (HyperText Markup Language) es el lenguaje de marcado que estructura el contenido de una página web. Define los elementos básicos como textos, imágenes, enlaces y secciones.

  • CSS

    • CSS (Cascading Style Sheets) es el lenguaje que controla la apariencia de una página web. Permite dar color, forma, tamaño, tipografía y diseño visual al contenido creado con HTML.

  • JAVASCRIPT

    • JavaScript es un lenguaje de programación que aporta interactividad a las páginas web. Permite realizar acciones dinámicas como animaciones, validaciones y respuestas a la interacción del usuario.

  • SASS

    • Sass es un preprocesador de CSS que añade herramientas como variables, anidación y funciones. Facilita la escritura y el mantenimiento de estilos de forma más organizada y eficiente.

  • GIT

    • Git es un sistema de control de versiones que registra los cambios en el código. Permite trabajar de manera colaborativa, organizar el desarrollo y recuperar versiones anteriores de un proyecto.

  • BOOTSTRAP

    • Bootstrap es un framework de diseño web que ofrece componentes predefinidos como botones, menús y sistemas de cuadrícula. Facilita la creación de sitios responsivos y con estilo profesional rápidamente.

  • GITHUB

    • GitHub es una plataforma en línea que permite alojar proyectos que usan Git. Facilita la colaboración, la gestión de código y el trabajo en equipo en la nube.

  • VERCEL

    • Vercel es una plataforma de despliegue que permite publicar aplicaciones y páginas web de forma rápida. Se integra con GitHub y actualiza automáticamente los proyectos al recibir cambios.
